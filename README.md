# Лабораторна робота №3

## Стек і вимоги

- Node.js 18+
- Vite 7
- React 19

## Структура проєкту

```
├─ index.html
├─ package.json
├─ vite.config.js
├─ public/
└─ src/
	├─ main.jsx            # Точка входу React
	├─ App.jsx             # Кореневий компонент застосунку
	├─ styles/
	│  ├─ index.css         # Базові стилі (ресети, дрібні утиліти)
	│  └─ App.css           # Тема та стилі інтерфейсу
	└─ components/
		├─ Header.jsx       # Шапка: назва, навігація, кнопка "Add Book"
		├─ Main.jsx         # Контейнер основного контенту
		├─ Footer.jsx       # Підвал із копірайтом
		├─ FilterBar.jsx    # Пошук, фільтр жанрів, сортування (поки без логіки)
		├─ BookList.jsx     # Список книг (демо-дані)
		└─ BookCard.jsx     # Картка книги
```

## Приклад реалізації компонентів

- `Header` - відображає назву застосунку, навігацію та кнопку додавання книги.
- `Main` - містить hero‑блок, панель фільтрів (`FilterBar`) та список (`BookList`).
- `Footer` - Номер лабораторної.
- `FilterBar` - пошук, фільтр за жанром, перемикач favorites (подання перехоплене, логіка не реалізована).
- `BookList` - використовує демо-дані та рендерить `BookCard`.
- `BookCard` - картка книги з обкладинкою, назвою, автором, жанром і рейтингом.

## Стилі й тема

У файлі `src/styles/App.css` налаштовано змінні теми (`:root`) і світлий книжковий стиль інтерфейсу: кольори фону/поверхонь, акцентні кольори, тіні, радіуси, ховер/фокус‑стани. Базові глобальні стилі зібрані в `src/styles/index.css` і не конфліктують із компонуванням.

## Як запустити локально

1) Встановіть залежності

```powershell
npm install
```

2) Запустіть режим розробки (з HMR)

```powershell
npm run dev
```

3) Зібрати продакшн‑білд

```powershell
npm run build
```

4) Попередній перегляд зібраної версії

```powershell
npm run preview
```
